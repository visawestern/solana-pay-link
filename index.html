How to use

  1. Pay: open pay.html → paste recipient wallet (NOT ATA) → amount (SOL ≤9dp, USDC ≤6dp, 0 allowed) → label/message/memo → Generate → Copy / QR-share via X/Discord → payer pays in Phantom/Solflare.
  2. Verify: open verify.html → same recipient + reference(s) from URL + expected amount → Check payment → CONFIRMED / MISMATCH / PENDING [finalized]. Use Re-check after payment, Search deeper for older history (5×20).
  3. Monitor: open monitor.html → Refresh → live BTC (blockstream.info) + EVM (blockcypher.com) balances. Pre-existing demo, disclosed per Colosseum rules.
  4. Local run: python3 -m http.server 8766 --directory hack/app → curl each page → expect 200.
